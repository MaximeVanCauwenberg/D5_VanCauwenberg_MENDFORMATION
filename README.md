# MENDFORMATION
**Make more. Waste less.**

**Cross Media Design I · D-5 Final Package**  
**Maxime Van Cauwenberg**

MENDFORMATION is a festival about transforming discarded objects through creativity, repair, exchange and hands-on experiences.

## Final package
- [D5_MENDFORMATION.pdf](D5_MENDFORMATION.pdf) · final project presentation, 21-page landscape PDF
- [Interactive prototype](https://www.figma.com/design/vIATL7YMWBXr6vaqgVWQ8d/Prototype-V2?node-id=0-1) · Second Chance Ticket, four-screen mobile experience

## Repository structure
| Folder | Files and purpose |
|---|---|
| `1_Touchpoint/` | Prototype link and final mobile-screen images |

## Touchpoint flow

The Figma prototype demonstrates the interaction and final ticket screen. The ticket code and QR are visual examples.
